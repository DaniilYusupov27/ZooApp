# Flappy Bird WPF

A Flappy Bird-style desktop game developed with **C# and WPF**.

## 🛠️ Technologies

* C#
* WPF
* .NET
* Object-Oriented Programming

## 📌 About the Project

This project is a desktop implementation inspired by the Flappy Bird gameplay concept.

The application demonstrates working with WPF, user interface elements, application logic, and event-driven programming.

## 🎮 Features

* Player-controlled bird
* Obstacles
* Collision detection
* Score tracking
* Game restart functionality

## 🎯 Purpose

This project was created as a practical project to improve C# and WPF development skills.
